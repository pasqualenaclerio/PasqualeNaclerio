# Hi 👋, I'm Pasquale Naclerio

### Electronic and Computer Engineer | High School Teacher | Telecommunications & Electronics

I'm an **Electronic and Computer Engineer**, specialized in **Telecommunications**, with a strong interest in electronics, embedded systems, measurement systems, programming, and education.

I currently teach technical and engineering-related subjects at **I.S.I.S. Sacile-Brugnera** in the province of Pordenone, Italy.

My academic and technical interests include **electronics, telecommunications, antennas, embedded systems, data acquisition, signal processing, and scientific computing**.
